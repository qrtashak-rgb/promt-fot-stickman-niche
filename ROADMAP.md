# Roadmap: Путь от нуля до Python Developer (Middle/Senior)

Этот документ — полная программа обучения. Прохождение строго
последовательное: следующий уровень не начинается, пока не закрыт контроль
знаний предыдущего. Часы — ориентировочные, при вдумчивой практике 5-7
часов/неделю общий курс занимает ~18-24 месяца.

**Итого уровней:** 41 (Level 0 – Level 40)
**Итого ориентировочных часов:** ~675 ч
**Итого проектов за курс:** 30+ (мини-проекты не считаются в это число)

Легенда по каждому уровню:
- **Темы / Подтемы** — что изучаем
- **Навыки** — что должен уметь делать студент на выходе
- **Практика** — формат задач (лёгкие/средние/сложные)
- **Мини-проект(ы)** — небольшая практическая работа по итогам уровня
- **Большой проект** — где предусмотрен, крупная работа, закрывающая блок уровней
- **Контроль знаний** — как проверяется усвоение перед переходом дальше

---

## Level 0 — Подготовка (≈10 ч)

**Темы/подтемы:** установка Python 3.12+, менеджеры версий (pyenv), выбор и
настройка IDE (VS Code / PyCharm), виртуальные окружения (`venv`), пакетный
менеджер `pip`, `pipx`, знакомство с REPL, интерпретатор vs скрипт, как
устроен запуск `.py` файла, базовые команды терминала, git init (без веток).

**Навыки:** настроить рабочее окружение с нуля, написать и запустить
`hello_world.py`, работать в терминале, понимать разницу между `python` и
`python3`.

**Практика:** 5 лёгких (настройка окружения, первые скрипты).

**Мини-проект:** консольный "hello, <имя>" с вводом через `input()`.

**Контроль знаний:** устный опрос "что происходит при запуске .py файла",
демонстрация рабочего окружения.

---

## Level 1 — Основы Python (≈25 ч)

**Темы:** переменные и типы данных (`int`, `float`, `str`, `bool`, `None`),
операторы (арифметические, сравнения, логические, присваивания), ввод/вывод,
форматирование строк (`f-string`, `.format`, `%`), приведение типов,
неизменяемость строк, базовая работа с числами (int/float precision).

**Подтемы:** динамическая типизация, duck typing (первое знакомство), PEP8
именование, комментарии и docstring-заглушки, оператор `is` vs `==`.

**Навыки:** объявлять переменные, конвертировать типы, писать
форматированный вывод, читать пользовательский ввод и валидировать его.

**Практика:** 5 лёгких / 5 средних / 5 сложных (калькуляции, работа со
строками, конвертация единиц).

**Мини-проекты:** (1) Конвертер валют (по фиксированному курсу), (2)
Простой калькулятор на 4 операции.

**Контроль знаний:** тест на 15 вопросов + код без подсказок (3 задачи).

---

## Level 2 — Управляющие конструкции (≈15 ч)

**Темы:** `if/elif/else`, тернарный оператор, `while`, `for`, `range`,
`break`/`continue`/`else` у циклов, вложенные циклы, `match/case` (3.10+).

**Подтемы:** truthy/falsy значения, short-circuit оценка, антипаттерны
(вложенность > 3 уровней), генерация таблиц/паттернов через циклы.

**Навыки:** писать условную и циклическую логику без лишней вложенности,
выбирать `for` vs `while` осознанно.

**Практика:** 5/5/5 (FizzBuzz-вариации, таблица умножения, игра "угадай
число", парсинг простых последовательностей).

**Мини-проект:** консольная игра "Крестики-нолики" (2 игрока, без ИИ).

**Контроль знаний:** рефакторинг "плохого" кода с глубокой вложенностью.

---

## Level 3 — Функции (≈20 ч)

**Темы:** объявление функций, аргументы (позиционные, именованные, `*args`,
`**kwargs`), значения по умолчанию, `return` vs побочные эффекты, area of
scope (LEGB), рекурсия, лямбда-функции, функции высшего порядка (`map`,
`filter`, `sorted` с `key`), `functools` (`reduce`, `partial`, `lru_cache`).

**Подтемы:** чистые функции, побочные эффекты, mutable default arguments
(классическая ловушка), замыкания (closures), декораторы — первое знакомство.

**Навыки:** проектировать функции с одной ответственностью, использовать
декомпозицию задачи на функции, писать рекурсивные решения.

**Практика:** 5/5/5 (рекурсивные задачи: факториал, Фибоначчи, палиндром;
функциональный стиль с map/filter/reduce).

**Мини-проект:** библиотека утилит (набор чистых функций с тестами вручную).

**Контроль знаний:** код-ревью собственной функции + объяснение замыкания
своими словами.

---

## Level 4 — Работа с файлами (≈10 ч)

**Темы:** `open`/`with`, режимы (`r`,`w`,`a`,`rb`), кодировки, чтение
построчно vs целиком, работа с `csv`, `json`, `pathlib` vs `os.path`.

**Навыки:** читать/писать текстовые и структурированные файлы, работать с
путями кроссплатформенно.

**Практика:** 5/5/5 (парсер логов, экспорт/импорт CSV, JSON-конфиг).

**Мини-проект:** консольный Todo-лист с сохранением в JSON-файл.

**Контроль знаний:** практическая задача — прочитать "грязный" файл и
привести данные к структуре.

---

## Level 5 — Исключения (≈10 ч)

**Темы:** `try/except/else/finally`, иерархия встроенных исключений,
`raise`, свои классы исключений, `assert`, контекст-менеджеры и исключения.

**Подтемы:** "проси прощения, а не разрешения" (EAFP) vs LBYL, антипаттерн
"голый except", логирование ошибок вместо `print`.

**Навыки:** проектировать корректную обработку ошибок без "проглатывания"
исключений, создавать доменные исключения.

**Практика:** 5/5/5 (валидация ввода, обработка ошибок файлового ввода-
вывода, кастомные исключения для доменной логики).

**Мини-проект:** доработка Todo-листа (Level 4) — устойчивость к битым
данным и некорректному вводу.

**Контроль знаний:** ревью кода с "плохой" обработкой ошибок → исправление.

---

## Level 6 — Модули (≈10 ч)

**Темы:** `import`, пакеты, `__init__.py`, `__name__ == "__main__"`,
структура проекта, стандартная библиотека (обзор), `pip`, `requirements.txt`,
виртуальные окружения глубже, PyPI, публикация простого пакета (опционально).

**Навыки:** организовывать код в модули/пакеты, отличать абсолютный и
относительный импорт, управлять зависимостями проекта.

**Практика:** 5/5/5 (разбить монолитный скрипт на модули, собрать пакет).

**Мини-проект:** переоформление Todo-листа в пакет с несколькими модулями
(`storage.py`, `cli.py`, `models.py`).

**Контроль знаний:** объяснить, что происходит при `import` (sys.modules,
однократная загрузка).

---

## Level 7 — ООП (≈35 ч)

**Темы:** классы и объекты, `__init__`, атрибуты экземпляра/класса, методы,
инкапсуляция (`_protected`, `__private`, property), наследование,
полиморфизм, абстрактные классы (`abc`), магические методы (`__str__`,
`__repr__`, `__eq__`, `__len__`, `__iter__` и др.), композиция vs
наследование, dataclasses.

**Подтемы:** MRO (Method Resolution Order), множественное наследование,
`super()`, статические и классовые методы, slots.

**Навыки:** проектировать объектные модели предметной области, выбирать
между наследованием и композицией.

**Практика:** 5/5/5 (иерархии классов: животные/фигуры/транспорт; магические
методы для кастомного контейнера).

**Мини-проекты:** (1) Библиотека книг (классы Book/Library с CRUD), (2)
Банковская система (Account/SavingsAccount с наследованием).

**Большой проект:** консольная RPG-игра с классами персонажей, инвентарём
и боевой системой (закрывает Level 1–7).

**Контроль знаний:** код-ревью + собеседование по ООП (10 вопросов).

---

## Level 8 — Продвинутый Python (≈30 ч)

**Темы:** итераторы и генераторы (`yield`, `yield from`), генераторные
выражения, декораторы (свои, с параметрами, `functools.wraps`), контекстные
менеджеры (`with`, `contextlib`), дескрипторы, метаклассы (обзорно), `*`/`**`
в распаковке, walrus-оператор, comprehensions (list/dict/set) продвинуто.

**Навыки:** писать эффективные ленивые вычисления через генераторы,
проектировать переиспользуемые декораторы и контекстные менеджеры.

**Практика:** 5/5/5 (кастомный итератор, декоратор кэширования/логирования,
контекстный менеджер для транзакций).

**Мини-проект:** собственная мини-библиотека декораторов (`@timer`,
`@retry`, `@cache`) с тестами.

**Контроль знаний:** объяснить разницу между итератором и генератором,
показать под капотом протокол итерации.

---

## Level 9 — Асинхронность (≈20 ч)

**Темы:** синхронность vs конкурентность vs параллелизм, `asyncio`,
`async`/`await`, event loop, корутины, `Task`, `gather`, `asyncio.Queue`,
таймауты и отмена задач, `aiohttp`/`httpx.AsyncClient`.

**Навыки:** писать асинхронный код для I/O-bound задач, избегать блокировки
event loop.

**Практика:** 5/5/5 (асинхронный загрузчик URL, асинхронный чат-эхо,
конкурентные запросы с ограничением параллелизма).

**Мини-проект:** асинхронный веб-скрапер нескольких страниц с прогресс-баром.

**Контроль знаний:** объяснить разницу между потоками, процессами и
асинхронностью (черновой ответ, углубим на Level 29-30).

---

## Level 10 — Работа с сетью (≈15 ч)

**Темы:** сокеты (`socket`), HTTP-протокол, `requests`/`httpx`, работа с
REST API клиентски, парсинг HTML (`BeautifulSoup`), Telegram Bot API
(`python-telegram-bot`/`aiogram`), веб-сокеты — обзорно.

**Навыки:** делать HTTP-запросы, обрабатывать ответы и ошибки сети,
интегрироваться с внешним API.

**Практика:** 5/5/5 (клиент к публичному REST API, простой TCP чат,
Telegram-бот с командами).

**Мини-проект:** Telegram-бот "погода/курс валют" через внешний API.

**Контроль знаний:** код-ревью бота + вопросы про HTTP-статусы/методы.

---

## Level 11 — Алгоритмы (≈30 ч)

**Темы:** нотация Big O (время/память), сортировки (bubble, insertion,
merge, quick, встроенная Timsort), поиск (линейный, бинарный), рекурсия и
backtracking, техники: two pointers, sliding window, prefix sum.

**Навыки:** оценивать сложность алгоритма, выбирать подходящий алгоритм под
задачу, писать решения без готовых библиотек.

**Практика:** 5/5/5 + еженедельные LeetCode Easy (постепенно Medium).

**Мини-проект:** визуализатор сортировок (консольный, пошаговый вывод).

**Контроль знаний:** решить 5 задач "вживую" без подсказок с объяснением
сложности.

---

## Level 12 — Структуры данных (≈25 ч)

**Темы:** списки/кортежи/множества/словари изнутри, связные списки, стек,
очередь, хэш-таблицы (принцип работы), деревья (BST), графы (списки/матрицы
смежности), куча (heap) и `heapq`, `collections` (`deque`, `Counter`,
`OrderedDict`, `defaultdict`, `namedtuple`).

**Навыки:** реализовывать базовые структуры данных с нуля, выбирать
подходящую структуру под задачу по сложности операций.

**Практика:** 5/5/5 (реализация стека/очереди/связного списка, обход
дерева, задачи на графы — обзорно, глубже на Level 11 продолжении).

**Мини-проект:** собственная реализация LRU-кэша на основе `dict` + связный
список.

**Контроль знаний:** тест на сложности операций (O(1)/O(n)/O(log n) по
структурам) + защита реализации LRU-кэша.

---

## Level 13 — Git (≈10 ч)

**Темы:** init/clone/add/commit/push/pull, ветки, merge vs rebase,
конфликты, `.gitignore`, `git log`/`diff`/`stash`, теги, GitHub flow
(issues, pull requests, code review в PR), conventional commits.

**Навыки:** вести историю изменений проекта, работать в команде через
ветки и PR, разрешать конфликты слияния.

**Практика:** 5/5/5 (сценарии: конфликт слияния, rebase интерактивно,
восстановление потерянного коммита через reflog).

**Мини-проект:** оформить один из предыдущих проектов по GitHub flow:
ветки, PR, описание, история коммитов.

**Контроль знаний:** практическая имитация конфликта и его разрешение.

---

## Level 14 — SQL (≈15 ч)

**Темы:** реляционная модель, `SELECT`/`WHERE`/`ORDER BY`/`GROUP BY`/
`HAVING`, `JOIN` (inner/left/right/full), подзапросы, агрегатные функции,
`INSERT`/`UPDATE`/`DELETE`, индексы (обзорно), нормализация (1NF-3NF).

**Навыки:** писать запросы средней сложности, проектировать простую
реляционную схему.

**Практика:** 5/5/5 (запросы к учебной БД: заказы/клиенты/товары).

**Мини-проект:** схема + запросы для мини-интернет-магазина (только SQL,
без кода).

**Контроль знаний:** написать 5 запросов на новую предметную область без
подсказок.

---

## Level 15 — PostgreSQL (≈20 ч)

**Темы:** установка/настройка, типы данных Postgres, транзакции и уровни
изоляции, индексы (B-tree, GIN и др. — обзорно), `psycopg2`/`asyncpg`,
ORM — `SQLAlchemy` (Core + ORM), миграции — `Alembic`, connection pooling.

**Навыки:** подключаться к БД из Python, писать модели ORM, управлять
миграциями схемы, работать с транзакциями из кода.

**Практика:** 5/5/5 (CRUD через SQLAlchemy, миграция схемы, транзакционная
операция с откатом при ошибке).

**Мини-проект:** консольное приложение "склад" с PostgreSQL + SQLAlchemy.

**Контроль знаний:** код-ревью моделей ORM + вопросы про N+1 проблему и
транзакции.

## Level 16 — Linux (≈15 ч)

**Темы:** файловая система, права доступа (`chmod`/`chown`), процессы
(`ps`, `top`, `kill`), пакетные менеджеры (`apt`), `bash`-скрипты, переменные
окружения, `cron`, работа с логами (`journalctl`, `tail -f`), SSH.

**Навыки:** уверенно работать в терминале Linux, писать простые bash-
скрипты автоматизации, деплоить/дебажить приложение на сервере.

**Практика:** 5/5/5 (bash-скрипт бэкапа, поиск по логам, настройка cron-
задачи).

**Мини-проект:** bash-скрипт деплоя Python-приложения на удалённый сервер
по SSH.

**Контроль знаний:** практическая задача на "живом" терминале (диагностика
процесса, съедающего память/диск).

## Level 17 — Docker (≈15 ч)

**Темы:** контейнеры vs виртуальные машины, `Dockerfile`, слои и кэш
сборки, образы, `docker-compose`, volumes, сети Docker, multi-stage build,
переменные окружения и секреты.

**Навыки:** контейнеризировать Python-приложение и его зависимости (БД,
кэш), писать `docker-compose.yml` для локальной разработки.

**Практика:** 5/5/5 (Dockerfile для FastAPI-заглушки, compose с Postgres,
оптимизация размера образа).

**Мини-проект:** докеризация проекта "склад" (Level 15): приложение +
Postgres в docker-compose.

**Контроль знаний:** объяснить слои образа и как ускорить сборку, ревью
Dockerfile.

## Level 18 — FastAPI (≈25 ч)

**Темы:** ASGI, роутинг, Pydantic-модели, валидация запросов, dependency
injection, middlewares, background tasks, автогенерация OpenAPI/Swagger,
работа с БД через SQLAlchemy (async), аутентификация (JWT/OAuth2 — базово).

**Навыки:** проектировать и реализовывать REST-сервис на FastAPI с БД и
валидацией.

**Практика:** 5/5/5 (CRUD-эндпоинты, кастомная валидация, DI для сервисов).

**Мини-проект:** API для Todo-приложения с авторизацией пользователей.

**Контроль знаний:** код-ревью API + вопросы про DI и жизненный цикл
запроса.

---

## Level 19 — Django (≈30 ч)

**Темы:** MVT-архитектура, модели и ORM Django, миграции, admin-панель,
формы, class-based views, Django REST Framework (serializers, viewsets,
routers), аутентификация/permissions, сигналы, middleware.

**Навыки:** строить полноценные веб-приложения на Django, проектировать

**Практика:** 5/5/5 (модели с связями, кастомный serializer, permission-
класс).

**Мини-проект:** блог-платформа с DRF API (посты, комментарии, лайки).

**Контроль знаний:** ревью моделей/сериализаторов + собеседование по
Django ORM (select_related/prefetch_related, N+1).

---

## Level 20 — REST API (углублённо) (≈15 ч)

**Темы:** принципы REST, версионирование API, пагинация, фильтрация,
HATEOAS (обзорно), идемпотентность, коды состояния HTTP правильно,
проектирование контрактов (OpenAPI-first), rate limiting.

**Навыки:** проектировать API "по учебнику" для промышленного использования,
писать понятную документацию API.

**Практика:** 5/5/5 (спроектировать контракт для новой предметной области,
добавить пагинацию/фильтры к существующему API).

**Мини-проект:** редизайн API блог-платформы (Level 19) под best practices
REST.

**Контроль знаний:** защита архитектурных решений API перед "заказчиком".

## Level 21 — Тестирование (≈20 ч)

**Темы:** пирамида тестирования, `unittest` vs `pytest`, фикстуры, моки и
патчи (`unittest.mock`), параметризация тестов, покрытие кода (`coverage`),
интеграционные тесты, тестирование FastAPI/Django (`TestClient`,
`pytest-django`), TDD — практика.

**Навыки:** писать unit- и интеграционные тесты, мокать внешние
зависимости, поддерживать высокое покрытие критичного кода.

**Практика:** 5/5/5 (тесты для существующих проектов: Todo API, банковская
система, склад).

**Мини-проект:** довести покрытие тестами API из Level 18 до 90%+.

**Контроль знаний:** код-ревью тестов + написание теста для "нечестного"
кода вживую (TDD-сессия).

---

## Level 22 — CI/CD (≈10 ч)

**Темы:** принципы CI/CD, GitHub Actions (workflows, jobs, matrix), линтеры
и форматтеры в пайплайне (`ruff`, `black`, `mypy`), автотесты в CI,
автодеплой (обзорно), pre-commit hooks.

**Навыки:** настраивать пайплайн CI для Python-проекта: линт → тесты →
сборка образа → (опционально) деплой.

**Практика:** 5/5/5 (настройка workflow, добавление матрицы версий Python,
кэширование зависимостей в CI).

**Мини-проект:** полноценный CI-пайплайн для проекта из Level 18/21.

**Контроль знаний:** ревью workflow-файла + разбор "падающего" пайплайна.

---

## Level 23 — Архитектура приложений (≈20 ч)

**Темы:** слоистая архитектура, Clean Architecture, Hexagonal/Ports &
Adapters, DDD — базовые понятия (Entity, Value Object, Aggregate, Repository),
разделение бизнес-логики и инфраструктуры, event-driven подходы (обзорно).

**Навыки:** проектировать структуру проекта, устойчивую к изменению
фреймворков/БД, разделять слои ответственности.

**Практика:** 5/5/5 (рефакторинг "толстых" вьюх/контроллеров в слои
service/repository).

**Мини-проект:** рефакторинг API блог-платформы под слоистую архитектуру.

**Контроль знаний:** защита архитектурной диаграммы проекта.

---

## Level 24 — Design Patterns (≈20 ч)

**Темы:** порождающие (Factory, Builder, Singleton), структурные (Adapter,
Decorator, Facade, Proxy), поведенческие (Strategy, Observer, Command,
Chain of Responsibility, Iterator, State), антипаттерны.

**Навыки:** узнавать паттерн в задаче и уместно его применять (без
переусложнения — YAGNI).

**Практика:** 5/5/5 (реализовать 1 паттерн из каждой группы на реальном
кейсе из своих проектов).

**Мини-проект:** внедрить Strategy + Observer в один из существующих
проектов (например, систему уведомлений).

**Контроль знаний:** собеседование "объясни паттерн и когда НЕ надо его
применять".

---

## Level 25 — Clean Code (≈10 ч)

**Темы:** именование, размер функций/классов, читаемость vs краткость,
комментарии (когда нужны/не нужны), форматирование, "код как проза",
рефакторинг "code smells".

**Навыки:** писать код, понятный без объяснений автора, проводить
самостоятельный рефакторинг.

**Практика:** 5/5/5 (рефакторинг заведомо "грязного" кода).

**Мини-проект:** полный рефакторинг самого раннего проекта курса (Level 1-2)
с текущим уровнем знаний.

**Контроль знаний:** сравнение "было/стало" с обоснованием каждого
изменения.

---

## Level 26 — SOLID (≈10 ч)

**Темы:** Single Responsibility, Open/Closed, Liskov Substitution, Interface
Segregation, Dependency Inversion — по отдельности, с примерами нарушения и
исправления.

**Навыки:** находить нарушения SOLID в коде и исправлять их обоснованно (не
догматично).

**Практика:** 5/5/5 (по одной задаче на каждый принцип + расширенная).

**Мини-проект:** рефакторинг части банковской системы (Level 7) под SOLID.

**Контроль знаний:** код-ревью с явным указанием, какой принцип нарушен и
почему.

---

## Level 27 — Типизация (≈10 ч)

**Темы:** `typing` (List, Dict, Optional, Union, Literal, Protocol,
Generic, TypeVar), статическая проверка `mypy`, `dataclasses` + типы,
`pydantic` для рантайм-валидации, gradual typing.

**Навыки:** типизировать проект целиком, использовать protocol-based
duck typing, настраивать mypy в CI.

**Практика:** 5/5/5 (типизация нетипизированного кода, generic-функции/
классы).

**Мини-проект:** полная типизация API из Level 18 + mypy strict в CI.

**Контроль знаний:** прогон mypy --strict на своём проекте без ошибок.

---

## Level 28 — Оптимизация (≈15 ч)

**Темы:** профилирование (`cProfile`, `line_profiler`, `memory_profiler`),
сложность алгоритмов на практике, кэширование (`lru_cache`, Redis —
предвкушение), генераторы вместо списков для памяти, `__slots__`, C-
расширения/`Cython`/`numpy` — обзорно.

**Навыки:** находить узкие места производительности и обоснованно их
устранять (не "оптимизация ради оптимизации").

**Практика:** 5/5/5 (профилирование медленной функции, оптимизация
запроса к БД, снижение потребления памяти).

**Мини-проект:** профилирование и ускорение самого тяжёлого места в
проекте "склад"/API.

**Контроль знаний:** отчёт "было/стало" с цифрами профилировщика.

---

## Level 29 — Многопоточность (≈15 ч)

**Темы:** GIL и его влияние, `threading`, `Lock`/`RLock`/`Semaphore`,
`ThreadPoolExecutor`, гонки данных и дедлоки, потоки vs asyncio: когда что.

**Навыки:** писать потокобезопасный код, осознанно выбирать между threading
и asyncio для I/O-bound задач.

**Практика:** 5/5/5 (потокобезопасный счётчик, пул потоков для скачивания
файлов, воспроизведение и исправление deadlock).

**Мини-проект:** многопоточный загрузчик файлов с прогресс-баром и лимитом
одновременных соединений.

**Контроль знаний:** объяснить GIL и его практические следствия на
собеседовании-симуляции.

---

## Level 30 — multiprocessing (≈10 ч)

**Темы:** `multiprocessing` (Process, Pool, Queue, Pipe), обход GIL для
CPU-bound задач, `concurrent.futures.ProcessPoolExecutor`, сериализация
(pickle) между процессами, `multiprocessing.shared_memory`.

**Навыки:** распараллеливать CPU-bound вычисления между ядрами процессора.

**Практика:** 5/5/5 (параллельный подсчёт/обработка большого датасета,
сравнение threading vs multiprocessing на CPU-bound задаче).

**Мини-проект:** параллельный обработчик изображений/данных с замером
ускорения относительно однопоточной версии.

**Контроль знаний:** сравнительный отчёт threading/multiprocessing/asyncio —
когда что выбрать.

---

## Level 31 — Redis (≈10 ч)

**Темы:** in-memory хранилище, структуры данных Redis (string, hash, list,
set, sorted set), TTL, паттерны кэширования (cache-aside), Redis как
брокер очередей — предвкушение Celery, `redis-py`.

**Навыки:** использовать Redis для кэширования и простых очередей/
счётчиков.

**Практика:** 5/5/5 (кэш ответов API, rate limiter на Redis, лидерборд на
sorted set).

**Мини-проект:** добавить кэширование в API (Level 18/20) через Redis.

**Контроль знаний:** объяснить cache invalidation стратегии и их риски.

---

## Level 32 — Celery (≈10 ч)

**Темы:** асинхронные фоновые задачи, воркеры, брокер (Redis/RabbitMQ),
result backend, периодические задачи (`celery beat`), ретраи и идемпотентность
задач, мониторинг (`flower`).

**Навыки:** выносить долгие/фоновые операции из HTTP-запроса в очередь
задач.

**Практика:** 5/5/5 (отправка email асинхронно, retry с backoff, задача
по расписанию).

**Мини-проект:** асинхронная обработка загруженных файлов (например,
генерация превью) через Celery в API-проекте.

**Контроль знаний:** ревью Celery-задачи на идемпотентность и обработку
сбоев.

---

## Level 33 — RabbitMQ (≈10 ч)

**Темы:** брокеры сообщений, AMQP, exchange/queue/binding, паттерны
(publish/subscribe, work queues, RPC), `pika`/`aio-pika`, dead-letter
очереди, надёжная доставка (ack/nack).

**Навыки:** проектировать обмен сообщениями между сервисами через очередь.

**Практика:** 5/5/5 (producer/consumer, работа с dead-letter queue, RPC
через RabbitMQ).

**Мини-проект:** разбить монолитный API на 2 сервиса, общающихся через
RabbitMQ (например, "заказы" и "уведомления").

**Контроль знаний:** объяснить гарантии доставки (at-most/at-least/exactly
once) и где их применять.

---

## Level 34 — Kafka (≈10 ч)

**Темы:** лог-ориентированная модель, топики и партиции, producer/consumer
group, offset, `kafka-python`/`aiokafka`, сравнение с RabbitMQ (когда что),
основы event-driven архитектуры/event sourcing (обзорно).

**Навыки:** проектировать событийный обмен данными между сервисами через
Kafka для задач с высокой пропускной способностью.

**Практика:** 5/5/5 (producer/consumer, consumer group с несколькими
воркерами, replay событий с определённого offset).

**Мини-проект:** событийный лог действий пользователя (audit log) через
Kafka для одного из проектов.

**Контроль знаний:** сравнительная таблица RabbitMQ vs Kafka с
обоснованием выбора под конкретный кейс.

---

## Level 35 — Kubernetes (≈15 ч)

**Темы:** Pod/Deployment/Service/Ingress, ConfigMap/Secret, масштабирование
(HPA — обзорно), `kubectl`, манифесты YAML, Helm — обзорно, локальный
кластер (minikube/kind).

**Навыки:** разворачивать контейнеризированное приложение в Kubernetes
локально, читать и писать базовые манифесты.

**Практика:** 5/5/5 (Deployment + Service для API, ConfigMap для настроек,
масштабирование реплик).

**Мини-проект:** развернуть проект из Level 17 (Docker) в локальном
Kubernetes-кластере с Service и ConfigMap.

**Контроль знаний:** объяснить путь запроса от Ingress до Pod.

---

## Level 36 — AWS (≈15 ч)

**Темы:** обзор основных сервисов (EC2, S3, RDS, Lambda, IAM, CloudWatch),
`boto3`, деплой Python-приложения на EC2/Lambda, работа с S3 из кода,
базовые принципы биллинга и безопасности (IAM roles, least privilege).

**Навыки:** разворачивать и настраивать простое облачное окружение для
Python-приложения, работать с облачным хранилищем из кода.

**Практика:** 5/5/5 (загрузка/скачивание файлов из S3, простая Lambda-
функция, чтение секретов из Secrets Manager).

**Мини-проект:** задеплоить API-проект на EC2 (или Lambda) с хранением
файлов в S3.

**Контроль знаний:** объяснить модель IAM (роли/политики) и типовые ошибки
безопасности в облаке.

---

## Level 37 — Production (≈15 ч)

**Темы:** логирование в production (`logging`, структурированные логи),
мониторинг и алертинг (Prometheus/Grafana — обзорно), обработка ошибок
(Sentry), graceful shutdown, health checks/readiness probes, конфигурация
через переменные окружения (12-factor app), секреты, откаты (rollback),
блю-грин/канареечные деплои — обзорно.

**Навыки:** готовить приложение к промышленной эксплуатации: наблюдаемость,
устойчивость к сбоям, безопасная конфигурация.

**Практика:** 5/5/5 (структурированное логирование, health check эндпоинт,
интеграция с Sentry).

**Мини-проект:** привести один из API-проектов к 12-factor виду с полным
набором production-практик.

**Контроль знаний:** production-чеклист по своему проекту с самопроверкой.

---

## Level 38 — Подготовка к собеседованиям (≈25 ч)

**Темы:** структура технического интервью (алгоритмы, система-дизайн,
поведенческое интервью), повторение Big O/структур данных/алгоритмов,
типичные вопросы по Python (GIL, mutable/immutable, генераторы, декораторы,
ООП, память), system design для backend (масштабирование, кэширование,
базы данных, очереди — синтез всего курса), поведенческие вопросы (STAR).

**Навыки:** уверенно проходить техническое интервью уровня Middle/Senior,
объяснять свои архитектурные решения.

**Практика:** серия mock-интервью (алгоритмические + system design +
поведенческие), разбор реальных вопросов из FAANG/крупных компаний.

**Контроль знаний:** минимум 5 полных mock-интервью с оценкой по критериям
(корректность, коммуникация, оптимальность решения, код-стиль).

---

## Level 39 — Портфолио (≈15 ч)

**Темы:** отбор и доработка 3-5 лучших проектов курса, оформление README
(проблема → решение → стек → архитектура → запуск), деплой демо
(облако/Docker), написание технических статей/заметок, оформление GitHub-
профиля, LinkedIn.

**Навыки:** презентовать свою работу так, чтобы её оценил нанимающий
менеджер за 2 минуты просмотра репозитория.

**Практика:** доработка README, диаграмм архитектуры, тестов и CI для
выбранных проектов.

**Большой проект:** один "flagship"-проект, объединяющий максимум
пройденного стека (FastAPI/Django + Postgres + Redis + Celery + Docker +
CI/CD + тесты), задеплоенный и доступный по ссылке.

**Контроль знаний:** защита портфолио как на реальном собеседовании.

## Level 40 — Карьера Python Developer (≈10 ч)

**Темы:** составление резюме под Python Developer вакансии, поиск вакансий

**Практика:** составление и ревью резюме, симуляция переговоров об оффере.

**Контроль знаний:** финальный экзамен курса — комбинированное
mock-интервью (алгоритмы + система-дизайн + код-ревью + поведенческое) с
итоговой оценкой готовности к позиции Middle/Senior.
